# Bayesian diffusivity-spectrum estimation for prostate multi-b diffusion MRI

Code and data for:

> **Why ADC works: Bayesian spectral decomposition of prostate multi-b diffusion MRI.**
> Patrick Remerscheid, William M. Wells III, Stephan E. Maier.
> Submitted to *Magnetic Resonance in Medicine*, 2026.

Multi-b diffusion MRI signal decays are modelled as a non-negative mixture of
exponentials, `S(b)/S0 = Σ_j R_j exp(-b D_j) + ε`, over a fixed eight-point
diffusivity grid. Recovering the fractions `R` is a discrete inverse Laplace
problem and is severely ill-conditioned (`cond(U) = 2.8e5`). This repository
estimates `R` two ways — a constrained-ridge **MAP** point estimate and full
Bayesian **NUTS** posterior sampling that also infers the per-ROI noise level —
and uses the posterior to establish *which* diffusivity compartments a given
b-value grid can actually resolve.

Applied to 149 prostate ROIs from 56 patients, the analysis shows that
tumour-versus-normal variation collapses onto a single restricted-to-free-water
axis, which is why the scalar ADC is already a near-optimal spectral
discriminant for lesion detection.

## Reproducing the manuscript

```bash
uv sync                                                        # Python >=3.10 + locked deps
uv run python -m spectra_estimation_dmri.biomarkers.recompute   # all reported numbers
```

`recompute.py` is the single source of truth for every quantitative claim in
the paper. It reads the ROI signal decays (`src/spectra_estimation_dmri/data/bwh/`)
and the 149 cached NUTS posteriors (`results/inference_bwh_backup/`, ArviZ
`.nc`, tracked in this repository) and writes to `results/biomarkers/`:

| Output | Manuscript |
|---|---|
| `features.csv` | MAP + NUTS fractions, posterior SDs, ADC, labels for all 149 ROIs |
| `auc_table.csv` | Table 1 — all detection AUCs at C = 0.1 / 1.0 / 10 |
| `identifiability.csv` | per-component posterior CV (Abstract, Methods, Discussion) |
| `adc_discriminant.csv` | ADC-vs-discriminant correlations (Results) |
| `adc_sensitivity.csv` | ADC sensitivity vector vs classifier weights (Figure 6) |
| `map_nuts_comparison.csv` | MAP-vs-NUTS agreement per component |
| `uncertainty_propagation.csv` | posterior propagated through the classifier (Figure 8) |

Figures are regenerated by the scripts listed in
[`scripts/README.md`](scripts/README.md), which maps every script to the figure
or number it produces.

To re-run the inference itself rather than use the cached posteriors
(~1 h for 149 ROIs on an 8-core Apple M1 Pro):

```bash
uv run python -m spectra_estimation_dmri.main dataset=bwh inference=nuts
```

## Layout

```
src/spectra_estimation_dmri/
  main.py                  Hydra entry point (configs/ selects dataset, prior, inference)
  models/prob_model.py     design matrix, priors, posterior
  inference/               map.py (constrained ridge NNLS) · nuts.py (PyMC) · gibbs.py (legacy)
  biomarkers/recompute.py  end-to-end analysis -> results/biomarkers/
  pixelwise.py             voxel-level estimation (Figure 9)
  data/bwh/                ROI signal decays + labels
configs/                   Hydra configuration groups
scripts/                   figure and analysis scripts (see scripts/README.md)
results/inference_bwh_backup/  149 cached NUTS posteriors (.nc)
paper/                     LaTeX sources and figures
```

## Data

ROI-averaged signal decays and tissue / Gleason-grade labels are openly
deposited at **[10.5281/zenodo.20787155](https://doi.org/10.5281/zenodo.20787155)**
and are also included here under `src/spectra_estimation_dmri/data/bwh/`.

- **Cohort**: 56 patients, 149 ROIs (40 tumour, 109 normal; PZ n = 81, TZ n = 68).
  `metadata.csv` lists 62 patient records; 56 have usable multi-b decays and
  enter the analysis.
- **Acquisition**: GE 3 T Discovery MR750, endorectal + pelvic phased-array
  coils, 15 b-values 0–3500 s/mm² in 250 s/mm² steps, three orthogonal
  directions combined into a trace decay.
- **Provenance**: the cohort of
  [Langkilde et al., *Magn Reson Med* 2018;79:2346–2358](https://pubmed.ncbi.nlm.nih.gov/28718517/),
  acquired under an IRB-approved protocol. The deposited data are
  de-identified and contain no patient-identifying information.

The single-slice pixel-wise demonstration (Figure 9) and the three-direction
ROIs (Figure S3) come from a separate, earlier acquisition outside this cohort.

## Key settings

| Parameter | Value |
|---|---|
| Diffusivity grid `D` | 0.25, 0.5, 0.75, 1.0, 1.5, 2.0, 3.0, 20.0 µm²/ms |
| b-values | 0 … 3500 s/mm², 15 values |
| Ridge weight λ (MAP) | 1e-3 (tuned on simulated ground truth) |
| NUTS | 2000 draws, 200 tune, 4 chains, `target_accept` 0.95 |
| Priors | `R ~ HalfNormal(√10)`, `σ ~ HalfCauchy(0.01)` |
| ADC | log-linear fit, b ≤ 1000 s/mm² (PI-RADS v2.1) |
| Classification | zone-specific L2 logistic regression, LOOCV, C = 1.0 |

## Use of language models

Large language models were used extensively as engineering and writing
assistants throughout this project: for code authoring and refactoring of the
analysis and figure scripts, for code review, for consistency checking of
reported numbers against the analysis outputs, and for language and structure
editing of the manuscript. The models used were Anthropic Claude (Sonnet and
Opus 4.x/5 families, via Claude Code) and Cursor's coding assistant; individual
commit trailers in the git history record which model assisted which commit.

Study design, analysis choices, interpretation, and all scientific claims are
the authors'. No result reported in the manuscript was accepted without
verification against the underlying data, and no AI-generated content is
presented as data or results.
